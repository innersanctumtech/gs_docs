# Geometria Sacra Docs

Public documentation and privacy policy for **Geometria Sacra**, an iPhone meditation app (iOS 17.0+) built by Inner Sanctum Tech. The app displays 15 sacred geometry images as a timed slideshow (60 seconds per image, Ken Burns transitions) with classical background music, and supports English/Portuguese. The free version shows Google AdMob banner ads, with a one-time in-app purchase available to remove them. This repository hosts the static HTML pages required for the app's App Store listing.

## Contents

- **`privacy-policy.html`** - The app's privacy policy. Covers what data is (and isn't) collected, Google AdMob's ad/device data collection, App Tracking Transparency, in-app purchase handling (processed by Apple), local-only data storage, and children's privacy (rated 4+).
- **`support.html`** - The app's support page. Describes how to use the app (start/pause, flip image, mute, language toggle), answers FAQs (removing ads, restoring purchases, audio troubleshooting), and lists system requirements (iOS 17.0+, iPhone).

Both pages are linked from the app's App Store listing and are plain, self-contained HTML with inline CSS.
